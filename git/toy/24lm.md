# Bring-up 
1. Khởi tạo repo workspace, tải file manifest (danh sách các git repo cần clone):
```bash
mkdir build-24lm && cd build-24lm 

repo init -u ssh://vgit.lge.com:29440/toyota/linux/manifest -b toyota_24lm_feature_bringup_260403 --reference=/data001/vc.integrator/mirror/toyota_26bev_release --repo-url="ssh://vgit.lge.com:29440/repo"
```
|Tham số|Ý nghĩa|
|-|-|
|-u ssh://vgit.lge.com:29440/toyota/linux/manifest|url của repo chứa file manifest|
|-b toyota_24lm_feature_bringup_260403|branch của manifest cần dùng|
|--reference=/data001/vc.integrator/mirror/toyota_26bev_release|dùng bản mirror local để tăng tốc độ, tránh download lại từ server|
|--repo-url="ssh://..."|url để tải tool `repo` nếu chưa có|

2. Download toàn bộ source code theo manifest:
```bash 
repo sync -cqj8 --no-tags
```
|Tham số|Ý nghĩa|
|-|-|
|-c|chỉ sync branch hiện tại, không tải toàn bộ lịch sử|
|-q|quiet - giảm output log|
|-j8|chạy 8 luồng song song để tăng tốc độ|
|--no-tag|bỏ qua git tags, tiết kiệm thời gian và dung lượng|

3. Tạo local branch trên tất cả các git repo vừa sync:
```bash
repo start toyota_24lm_feature_bringup_260403 --all
```
