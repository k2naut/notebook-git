# SDLC (Software Development Life Cycle)

## Tổng quan

SDLC là quy trình có cấu trúc để lập kế hoạch, tạo ra, kiểm thử và triển khai phần mềm.

```
1. Planning
2. Requirements 
3. Design 
4. Implementation 
5. Testing 
6. Deployment 
7. Maintenance
```

---

## Các mô hình SDLC phổ biến

| File | Mô hình | Đặc điểm |
|------|---------|----------|
| [V-Model](v-model.md) | V-Model | Verification & Validation song song, safety-critical |
| [Waterfall](waterfall.md) | Tuần tự tuyến tính, yêu cầu cố định | — |
| Agile/Scrum | Iterative, linh hoạt, feedback sớm | — |
| Spiral | Hướng rủi ro, nhiều vòng lặp | — |
| Kanban | Flow liên tục, không fixed sprint | — |

---

## So sánh tổng quát

```
Yêu cầu rõ ràng, không đổi  →  Waterfall / V-Model
Yêu cầu thay đổi thường xuyên →  Agile / Scrum
Rủi ro cao, hệ thống phức tạp →  Spiral
Safety-critical (auto, medical) → V-Model
```
